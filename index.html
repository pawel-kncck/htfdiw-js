§ 00

The architecture, at a glance

Six pieces conspire to make asynchronous JavaScript work. Three of them aren’t part of JavaScript at all — they belong to the browser. Click any piece to see what it actually does.

Begin

Click any piece of the diagram

Each box is a part of the machine that runs your code. Some live inside the JavaScript engine. Some are part of the browser around it. Knowing which is which is the whole point.

  • Region A — the JS engine
  • Region B — the browser

✱  Most of what looks like “JavaScript doing work” is actually the browser doing work. The engine sits patiently in the middle, processing one frame at a time.
